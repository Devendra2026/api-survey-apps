## Verified as correct (no change needed)

- **Clerk JWT verification**: signature/issuer/expiry via `verifyToken`, `azp` allowlist enforced when present, clock skew bounded, email-based account rebinding only after Clerk-verified email. Disabled users rejected before profile sync.
- **Dev auth bypass** (`ALLOW_DEV_AUTH`) is gated on `NODE_ENV !== "production"`; production compose sets `NODE_ENV: production`.
- **Clerk webhook**: Svix signature verified on raw body; rejects when secret unset.
- **Throttling**: per verified user id, else per `req.ip` after a single trusted proxy hop.
- **Photos, floors, co-owners, survey audits**: every read/write goes through `assertReadableSurvey` / `assertEditableSurvey`. Saved views scoped by `userId`.
- **Uploads**: images validated by MIME + magic bytes, 5 MB limit, memory storage bounded by that limit.
- **ULB portal API keys**: stored as hashes, looked up by hash, ULB must be ACTIVE.
- **Report downloads**: restricted to `createdById = user.id`.
- **Prod MinIO**: bucket private (no anonymous policy), not exposed via Traefik.
- **Role grants**: `canGrantRole` ceilings + tenant checks on assign/deactivate.
