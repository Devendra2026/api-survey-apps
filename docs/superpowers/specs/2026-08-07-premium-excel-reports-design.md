# Premium Multi-Sheet Survey & QC Excel Reports

**Date:** 2026-08-07  
**Status:** Approved (Approach 1 — Sections 1–2)  
**App:** `api-survey-apps`

## Problem

Ward-wise Survey Data and QC Final Excel downloads need a premium, government-style presentation for commissioners, tax officers, QC, and auditors: multi-sheet workbooks, report banner, print-ready layout, soft missing-data highlighting, Survey-only vs QC+tax separation.

## Locked decisions

| Decision       | Choice                                                                      |
| -------------- | --------------------------------------------------------------------------- |
| Packaging      | Two workbooks: Survey = Dashboard + Survey Data; QC = Dashboard + QC Final  |
| Survey sheet   | Survey/capture fields only — no tax/demand                                  |
| QC tax headers | Full brief set; fill backend-supported values; placeholders for unsupported |
| Validation     | Soft only — light red + comment; never block export                         |
| AutoFilter     | Off by default                                                              |
| Charts         | Deferred (KPI tables only on Dashboard)                                     |
| Scale          | Streaming + O(1) dashboard counters                                         |

## Workbook chrome

Banner: Municipality name, report title, ward name/number, export datetime, generated by, total records.  
Theme: blue / white / gray. Bold wrapped centered headers, alt row shading, thin borders, landscape print, repeat header row, freeze header + Survey ID column.

## Survey Data columns (Sections A–H)

Survey info, owner, address, classification, building (G–3 usage/area + plot/total built-up), utilities, GIS, attachment counts. No tax columns.

## QC Final columns

Survey columns + QC Status / Approved By / Date / Remarks + Tax Zone / Category / Rate + Land/Building/Water/Drainage/Conservancy/Other + Current Demand / Arrears / Penalty / Interest / Total Demand.  
Map: Building Tax ← propertyTax; Water/Drainage/Penalty/Current+Total Demand ← `computeExportTaxSummary`. Others `—`/`0`.

## Mandatory soft-highlight

Survey ID, Owner Name, Ward, Parcel Number, Property Type, Property Usage, Plot Area.

## Non-goals (v1)

Charts, AutoFilter on, full arrears/land tax engine, photo embeds, filename changes, monorepo client exporter.
